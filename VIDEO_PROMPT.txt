==== HOW TO MAKE THE REAL ANIMATED TELUGU VIDEO ====
1) Make 3 silent cartoon clips (5-8 sec each) in any AI video tool. Use the SAME character picture as reference so mother/father/baby look the same.
2) Make Telugu voices from the DIALOGUE below (a tool with Telugu voices, or record family/friends/yourself).
3) Join clips + voices + Telugu subtitles in CapCut / VN (free). Export MP4, 720p, under 50 MB.
4) Save as public/amma.mp4, set video:"amma.mp4" in public/config.js, then: git add . ; git commit -m video ; git push
